# Uptime City

Talk to your hero to build a backend as a small 3D city - load balancers, servers, caches, databases - then watch a stress test pour traffic through it. A chaos card hits, buildings start to burn, and you get one shouted command to save it. Learn system design by watching your city survive or melt.

Built for the Meta Global AI Developer Hackathon (Cerebral Valley, October-November 2026), Startups track, by CandiVision.

## Built during the hackathon

Every file in this repository was written during the event. Work started on 2026-10-26 21:34 EDT (2026-10-27 08:34 +07 in Hanoi), after kickoff, once the organisers confirmed that building could begin from kickoff. The git history shows each step. Nothing was copied from earlier projects; third-party libraries are used as dependencies.
